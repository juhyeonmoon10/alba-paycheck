# 알바정산

청소년 알바생이 받아야 할 급여를 스스로 검산하고, 사장님께 보낼 말까지 만들어 주는 웹 서비스.

고등학교 창업 프로젝트 프로토타입입니다.

## 기능

**알바생 모드 (무료)**
- 기본급 · 주휴수당 · 야간/연장 가산 자동 계산
- 만 18세 미만 연소근로자 기준(1일 7시간 · 주 35시간) 반영
- 18세 미만 야간근로 제한, 최저임금 미달 경고
- 5인 미만 사업장 가산수당 미적용 반영
- 사장님께 보낼 문의 메시지 자동 생성

**사장님 모드**
- 표준 근로계약서 자동 작성 (연소근로자용 자동 전환)
- 친권자 동의서 자동 작성
- 급여명세서 자동 작성

## 개인정보

입력한 내용은 서버로 전송되거나 저장되지 않으며, 브라우저 안에서만 계산됩니다.

## 고지

세전 기준 개략 검산 도구이며 법률 자문이 아닙니다. 작성된 서류는 표준 양식을 바탕으로 한 초안이므로 최종 확인 후 사용하십시오. 임금 관련 상담은 고용노동부 고객상담센터 1350(무료)에서 받을 수 있습니다.
