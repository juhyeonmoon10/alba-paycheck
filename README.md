# 알바정산

청소년·외국인 근로자를 위한 모바일 계약 이해·임금 확인 시제품입니다. 발표자료에 사용한 웹 시제품을 바탕으로 인터랙션과 모바일 접근성을 개선했습니다.

## 실행

`index.html`을 브라우저로 열거나 정적 웹서버에서 실행합니다. 별도 빌드 및 외부 라이브러리는 없습니다.

## 기능

- 근로조건 입력, 확인 항목 안내, 계약서 초안 및 인쇄·PDF 저장
- 예상 임금과 실제 수령액 비교
- 영어·베트남어·중국어 핵심요약 Beta
- 클릭 가능한 첫 화면 단계 예시, 입력 진행 표시와 실시간 임금 미리보기
- 등장·전환 효과, 움직임 끄기, 운영체제의 동작 줄이기 설정 지원, 키보드 탭 이동

## 개인정보 및 한계

입력은 현재 페이지 메모리 안에서만 처리하며 서버 전송·자동 저장·분석 도구를 사용하지 않습니다. 웹 호스팅 제공자의 일반 접속 로그와 별개로, 서비스는 사용자의 입력값을 수집하지 않습니다.

일반 정보 및 문서 초안용 시제품으로 법률상담·사건대리를 제공하지 않습니다. 임금은 세전 단순 추정이고, 점수는 법률 판단이 아닙니다. 다국어 요약은 전문 번역 검수 전 Beta입니다. 기관 문의·전문가 연결은 데모 기능입니다. 임금 계산의 기준연도는 2026년입니다.

## GitHub Pages

이 폴더의 `index.html`, `styles.css`, `app.js`, `ui.js`와 `.nojekyll`을 같은 위치에 배포합니다. 기존 프로젝트의 상대 주소를 그대로 사용합니다.
